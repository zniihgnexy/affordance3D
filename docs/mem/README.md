# mem 分支：以动作与交互组织的环境记忆

**分支：** `mem`（与另一研究方向按分支名区分）｜**建立：** 2026-11-10｜**状态：** 探索 / 讨论中

本分支研究记忆系统本身，不做机器人控制：在 SceneFun3D 类室内场景的视频上，为每个功能部件记住可以做什么动作、动作的结果，以及实际发生过的动作序列，检验动作和人—物 affordance 信息能否帮助构建与检索环境记忆，并用人形接近和操作物体的画面展示结果。记忆从视频构建：只使用简单深度和设备自带位姿，三维重建只用于训练标签和评测真值。

`main` 上的已有文档（Pipeline v3、11 月 5–6 日交接、文献档案 P01–P116、E0 记录、组会报告）作为共享的 brainstorming 基础，本分支不修改它们。[项目总控](../项目总控.md)的范围和维护规则继续适用：总控第一、三节已包含"环境随时间的变化"和"可以优先研究记忆系统本身"，本分支的讨论不构成对总控的修改。
