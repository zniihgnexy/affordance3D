# mem 分支：以动作与交互组织的环境记忆

**仓库：** affordance3D（自 2026-11-10 起只承载记忆方向，`mem` 已并入 `main`）｜**建立：** 2026-11-10｜**状态：** 探索 / 讨论中

本方向研究记忆系统本身，不做机器人控制：在 SceneFun3D 类室内场景的视频上，为每个功能部件记住可以做什么动作、动作的结果，以及实际发生过的动作序列，检验动作和人—物 affordance 信息能否帮助构建与检索环境记忆，并用人形接近和操作物体的画面展示结果。记忆从视频构建：只使用简单深度和设备自带位姿，三维重建只用于训练标签和评测真值。

**与 VLA 方向的关系：** VLA 方向自 2026-11-10 起在独立仓库 `affordance-vla` 中进行，两个仓库互不包含对方的新内容。本仓库中 11 月 9 日及之前的文档（Pipeline v3、11 月 5–6 日交接、文献档案 P01–P116、E0 记录、组会报告）是两个方向共同的 brainstorming 基础，保留用于追溯。[项目总控](../项目总控.md)的范围和维护规则继续适用：总控第一、三节已包含"环境随时间的变化"和"可以优先研究记忆系统本身"，本方向的讨论不构成对总控的修改。

## 运行环境（2026-11-10 起）

- **位置：** 实验室 A6000 服务器。代码只放在 home 下的仓库里；`data`、`runs`、`third_party` 是指向数据盘的链接，模型缓存和 conda 环境也在数据盘。报告 notebook 生成的视频放在 `report/assets`，由 git 跟踪，拉取仓库即可得到；其中的 `external`（各数据集官方示意图）不进 git，用 `scripts/download_report_images.sh` 下载。
- **使用：** `source scripts/remote/env.sh` 激活环境；首次安装用 `bash scripts/remote/setup.sh`，公开数据用 `bash scripts/remote/fetch_data.sh`。SMPL-X 需要本人注册后自行放入 `data/body_models/smplx/`。
- **GPU：** 代码默认不使用 CUDA；只有队列作业设置 `AFFORDANCE3D_DEVICE=cuda` 时才用 GPU。
