# Affordance 与三维记忆：创新性、评测与机器人接口

**研究备忘，2026-10-28；非完整系统性文献综述。** AROS 是可选的历史与方法参考，不作为本方向的强制前提。本文不修改项目总控。

## 1. 初步创新性判断

单独声称“把 affordance 加入记忆”“动态更新记忆”或“将 3D 和记忆接入 VLA”已不足以建立明确创新：

- [AFFORDMEM](https://arxiv.org/abs/2605.11616)（2026 预印本）以跨场景标注示例和场景内 3D 图组织记忆，支持功能区域定位；不同于以交互结果学习连续几何关系表征。
- [MessyMem](https://messymem.github.io/)（CoRL 2026）把交互获得的属性和结果写入空间场景图，支持后续任务复用。
- [SOMA](https://proceedings.mlr.press/v306/li26ay.html)（ICML 2026）将多视角空间记忆用于视野外 VLA 操作。
- [GeoMem-VLA](https://arxiv.org/abs/2610.29866)（2026-10 预印本）以三维监督训练几何 token，并融入时间记忆指导动作；它不是用户拟议系统的验证。
- [O³Afford](https://proceedings.mlr.press/v305/tian25b.html)（CoRL 2025）已利用物体对点云与语义特征进行 3D affordance grounding 并服务运动规划。它并不等同于时序动态记忆。

**候选研究切口（尚未证明空白）：** 将不同局部物体—环境几何、观察证据及交互后果关联为可更新的记忆，研究其在意图变化、遮挡、场景变动及未见物体—环境组合中的复用。需与上述及其他最接近方法逐一核对设置，并通过受控实验验证。

具体可证伪假设：相同观测、训练与策略预算下，保存可查询的局部关系及其有效性、时间和交互结果，能否较通用几何记忆改善新组合中的条件后果预测、降低遮挡后过期信息误用，并最终改善同一策略的闭环任务成功？如果没有任何收益，或收益只来自更多输入和参数，则该假设不成立。几何、时间、交互经验的贡献须分别消融。

注意定义目标：静态邻近与空隙是 affordance 线索，不自动构成行动可行性或交互经验。物体质量、固定方式和机器人形态无法总由 RGB-D 几何唯一确定。失败也不自动等于目标不可能。

## 2. 可用于首版与扩展的资源

| 资源 | 适用层次 | 局限 |
| --- | --- | --- |
| [ManiSkill 3](https://github.com/mani-skill/ManiSkill) | 仿真器：生成 RGB-D 和控制的场景变化，构建算法层的自定义记忆查询与可核验真值。 | 是平台，不自带本项目的完整 affordance-memory benchmark；权限、相机位姿和具体版本需验证。 |
| [SceneFun3D](https://scenefun3d.github.io/) | 真实 3D 场景中细粒度功能区域和动作信息，用于检验 affordance grounding。 | 存在功能 mask 与类别标注；静态功能定位不能单独验证动态记忆、连续交互或机器人成功。 |
| [RoboMME](https://robomme.github.io/) | 后续记忆增强机器人策略评测；Permanence 关注遮挡与环境变化。[训练数据格式](https://github.com/RoboMME/robomme_benchmark/blob/main/doc/h5_data_format.md)列出 RGB-D、相机内外参和机器人动作。 | 需要策略接口；task success 不能单独证明局部几何关系记忆的质量。坐标约定和在线评测允许的观测需按任务及版本核查。 |
| [MIKASA-Robo-VLA](https://mikasarobo.github.io/benchmarking.html) | 多种记忆依赖的 VLA 仿真评测，提供分 horizon 的任务协议。 | 不等于专门的对象—环境 affordance 评测，完整任务训练资源未知。 |
| [LIBERO-Mem](https://libero-mem.github.io/) | 记忆依赖机器人操作的补充测试。 | 需要核验所需传感器与权限；不能直接测所有几何 affordance。 |

推荐起点是 ManiSkill 自定义小规模关系查询 + SceneFun3D 功能理解外部验证；未来再针对确定的策略使用 RoboMME 或 MIKASA。场景真值若用于动态跟踪输入，必须标为特权信息并与仅观察输入分开。

## 3. 各阶段的数据接口

**构建记忆：** 连续 RGB-D、相机内参与位姿、时间戳；还需目标锚点/区域或类别无关的候选追踪方法。输出为局部 3D 几何、相对关系、历史与观测状态；仅此仍不自动获得动作或物理后果。

**交互理解增强：** 增加已执行动作或其他可观察干预、前后状态，以及目标状态/示范或语言任务；按方法选择接触、碰撞、成功/失败监督。输出可以是候选局部区域/方向、预测状态变化、条件可行性或潜在 token。只看成功示例可能无法识别失败，动作没找到不等于任务物理上不可能。

一个概念查询是 `p(结果 | 记忆, 意图, 候选动作, 机器人状态)`；是否能估计可靠概率取决于数据与校准，不能把未校准分数称为概率。仅提供意图而没有候选动作时，需要明确定义它是在对什么动作分布求可行性。

**机器人策略：** 常见输入包括当前相机观测、语言或目标、机器人本体状态、可查询的记忆/特征。常见输出是若干步末端位置和姿态增量及夹爪指令，或者关节目标；坐标系、单位、控制频率、执行机器人及动作归一化均依具体模型和任务确定。运动规划、逆运动学和控制器将策略输出转成可执行动作；接触/力和物理安全还要单独处理。训练对接通常需要与机器人具身及动作空间对齐的示范或交互数据。

## 4. 显式与隐式接口

| 接口 | 传递内容 | 优点 | 局限/代价 |
| --- | --- | --- | --- |
| 显式 | 3D 区域、点、方向、候选目标位姿、局部运动/空间条件与可见性。可供规划器、外部模块或受支持的条件输入使用。 | 易调试、可追溯；可先用冻结策略做可行性验证。 | 某个现有 VLA 未必原生支持任意 3D 输入；需要 grounding、规划或接口适配；难以完整表达未知因素。 |
| 隐式 | 由可学习编码器将检索到的记忆变成一组特征 token，使用 adapter 或 cross-attention 与 VLA 融合。 | 表示灵活，几何与意图可在特征中组合；不要求中间文本。 | 通常需要模型改造、对齐训练或机器人示范；不保证真的使用记忆，解释与诊断较困难。 |
| 混合 | 记忆保留可检查几何/时效/证据，训练 token 给策略，并使用显式 probes 验证。 | 兼顾算法分析和策略接口，符合目前研究重点。 | 系统更复杂；需要比较同计算量的显式、隐式与混合对照。 |

[Affordance Field Intervention](https://vla-afi.github.io/) 展示三维场和外部技能辅助冻结 VLA；其“memory trap”指训练轨迹固化，不是持久三维记忆。[PointVLA](https://pointvla.github.io/) 用轻量模块向冻结的 action expert 注入点云特征，但其系统和任务仍依赖训练示范。[GeomVLA](https://arxiv.org/abs/2609.13812) 使用三维场景与运动 token 条件化动作；[AffordanceVLA](https://arxiv.org/abs/2606.06155) 使用结构化 affordance 中间表示。它们证明不同接口有研究路径，并不保证任意已有 VLA 可无需训练地接收本项目的记忆。

**建议：** 第一阶段构建/评测外部几何与证据记忆；再以显式几何结果接简单规划器作端到端诊断；随后在同一个可用策略上训练轻量 token adapter，比较显式与隐式。VLA 是可选后续评测，不把它当成记忆算法创新的前提。
