# 初步研究问题与 Pipeline：视频驱动的功能性三维记忆

**状态：讨论稿，不改变项目总控**  
**更新：2026-10-28**

## 1. 当前选择与工作假设

项目负责人选择第一阶段重点为**三维记忆及其行动推理能力**，初始输入为**仿真 RGB-D 视频及已知相机位姿**。真实机器人、VLA 微调和纯单目重建不作为第一阶段的前提。下文把物体放置作为便于具体讨论的候选任务，而非已经确定的项目方向。

建议首先研究：**在部分可观察、场景可能变化时，记录局部几何交互条件及其证据状态的三维记忆，能否帮助系统作出更可靠的行动位置判断，并识别何时需要重新观察？**

这包含三个可分别否定的假设：

- H1：当任务所需区域离开当前视野时，使用相同历史观测的记忆可以改善行动候选判断。
- H2：在已有三维记忆基础上，显式表示支撑、净空等任务条件，可能提高对未见物体和场景的迁移能力。
- H3：记录观测时间、可见性及证据一致性，并在证据不足时请求重观察，可能降低使用过期或未知信息导致的错误；应同时测量重观察代价。

几何是必要线索之一，不保证摩擦、质量、承重、可达性或真实世界的动作成功。创新性仍需系统检索和对比实验确认。

## 2. 候选任务：离开视野后的放置决策

1. 仿真相机沿预设轨迹观察桌面环境，记录带时间戳的 RGB-D 帧、相机内参与位姿。
2. 部分潜在放置区域随后离开当前视野；另一个物体可能移动或占据其中一个区域。
3. 系统收到目标物体及放置请求，输出候选三维放置位姿、置信度，或请求重新观察。
4. 使用共同的几何检查、规划器及仿真物理检验候选位姿的碰撞、可达性和放置稳定性。

实验必须区分**变化被观测到**与**变化完全未被观测到**：后者无法仅凭旧视频确定新状态，合理目标是标记未知、保守判断或重观察，而不是声称推断出了隐藏真相。安排无变化控制组，防止系统靠一味重观察获益。

## 3. 模块化 Pipeline

```text
仿真场景与轨迹
  → RGB-D 视频 + 相机内参 / 已知位姿
  → 深度反投影与跨帧配准、融合
  → 持久三维记忆：局部几何、实例或区域、观测时间、可见性与证据
  → 任务查询：目标物体 + 动作（候选为放置）
  → 几何交互推理：候选支撑区域、接触、净空、碰撞和未知空间
  → 决策：候选位姿 / 不确定 / 重观察
  → 共同规划与仿真执行 → 成功与失败分析
```

- **观测层：** 深度与相机位姿均来自仿真；明确记录坐标系、度量单位、帧率、深度有效范围及相机轨迹。状态真值只用于标注、诊断和 oracle；不得混入普通方法的输入。
- **记忆层：** 初期可用体素占据/自由/未知空间及物体局部点云，按时间关联；每条记录保留最后观察时间、可见性、证据来源和不确定性。具体表示、关联和置信度计算待小实验验证。
- **更新层：** 只在当前视野支持时更新、覆盖或标记旧信息；遮挡不等同于消失。三维数据关联错误和相机噪声应作为独立误差来源记录。
- **推理层：** 先用可解释规则建立基线，如支撑面面积与倾斜度、目标尺寸、碰撞和上方净空；语义帮助识别目标，但不假定同类别都可放置。AROS 的接近和空余空间仅作设计启发，不能直接等同于机器人 affordance。
- **决策层：** 允许输出“不知道/需要再看”，并记录观察动作、代价及预算。实际执行依赖机器人模型、运动学和仿真物理，候选得分不能代替成功验证。

## 4. 对照与评测设计

**同一组场景、相机轨迹、目标物体、历史观测和行动执行接口**下，比较：

| 系统 | 目的 |
| --- | --- |
| 当前帧，无历史记忆 | 观察部分可见时的基础表现 |
| 历史帧/2D 记忆 | 排查收益是否只是来自更多历史信息；尽可能匹配观测和存储预算 |
| 通用三维几何记忆 | 检验三维表示本身的作用 |
| 三维记忆 + 功能条件 | 检验支撑、净空等任务表示的额外作用 |
| 完整方法：功能条件 + 证据状态 + 可选重观察 | 检验时效、不确定性和主动复查 |
| 仿真真值 oracle | 诊断感知和记忆误差，并给出参考上界；并非可部署方法 |

主动重观察实验中，所有能观察的对照方法须获得相同的观察权限和预算，另报告固定预算和无重观察结果。若存在训练过程，记录训练数据和计算预算；不能单凭一种弱基线证明创新。

**场景分组：** 已见/未见布局，已见/未见物体实例与类别，遮挡长度变化，无变化、观察到变化、未观察到变化。场景、资产和轨迹须按预先定义的划分隔离，避免相邻帧泄漏。

**主要指标：** 放置任务成功率及置信区间、候选可行性精确率/召回率；无安全候选时的拒绝表现；不确定性校准及错误风险与覆盖率；过期信息错误使用率、重观察次数/时间和成功率的权衡。辅助记录局部几何误差、实例关联错误、更新延迟和运行开销。以场景/轨迹为单位做多随机种子重复，并明确试验次数与统计单位。

**必要消融：** 时间与可见性记录、变化更新、功能几何条件、重观察策略、几何/语义输入。不同模块产生的差异应归因于对应指标，不把整个系统成功率变化自动解释为某个模块有效。

## 5. 分阶段实施与退出条件

1. **概念验证：** 选一个可重复生成的小型仿真场景，录制 RGB-D 和位姿；用仿真真值构造记忆与候选，验证可视化、查询和仿真评测。若任务没有可重复的记忆依赖，先修改实验设计。
2. **感知版基线：** 用深度反投影和跨帧融合替代真值几何；建立当前帧、2D 历史和普通 3D 基线，量化重建与关联误差。验证同一接口和观测预算。
3. **研究方法：** 加入功能条件、观测时效和未知状态；测试动态变化、未见场景与物体，分离各因素。对隐藏变化，比较拒绝和重观察策略及成本。
4. **扩展验证：** 若前三阶段显示清晰收益，选择适配现有 memory benchmark 的任务，或接入统一的仿真操作模块；再评估 VLA 接口。单目 RGB 和真实视频另行处理深度、尺度和相机位姿估计，不把 RGB-D 结论当成纯视频结论。

平台优先做最小安装与传感器接口试验后再确定。[MIKASA-Robo](https://github.com/CognitiveAISystems/MIKASA-Robo) 是现成的记忆任务候选；[LIBERO 与 LeRobot 文档](https://huggingface.co/docs/lerobot/libero)描述了无头渲染配置，但现成数据是否提供本项目所需深度、轨迹及场景变化需逐项检查，可能需要自行从仿真采集。尚未验证学校服务器驱动、5060 显存和环境兼容性。

## 6. 与已有研究的关系：初步查证，非完整新颖性审查

- [DynaMem](https://dynamem.github.io/) 已构建并更新动态三维语义记忆，支持移动操作中的物体定位。不能将“动态 3D 记忆”本身作为新颖点。
- [3D-Mem](https://openaccess.thecvf.com/content/CVPR2025/papers/Yang_3D-Mem_3D_Scene_Memory_for_Embodied_Exploration_and_Reasoning_CVPR_2025_paper.pdf) 从 RGB-D 与相机位姿构建视觉记忆快照并用于探索推理。
- [Embodied VideoAgent](https://openaccess.thecvf.com/content/ICCV2025/papers/Fan_Embodied_VideoAgent_Persistent_Memory_from_Egocentric_Videos_and_Embodied_Sensors_ICCV_2025_paper.pdf) 研究连续观测、动态场景记忆与具身行动。
- [SAM2Act+ / MemoryBench](https://arxiv.org/abs/2501.18564)、[MIKASA-Robo](https://arxiv.org/abs/2502.10550) 和 [RoboMME](https://robomme.github.io/index.html) 已研究或评测机器人操作记忆，需对照其任务设置、输入和实现成本。
- [RoboEXP](https://jianghanxiao.github.io/roboexp-web/) 已结合交互探索与行动条件场景图；因此“主动观察 + 场景记忆”也不能单独视作新贡献。
- [RoboSpatial](https://openaccess.thecvf.com/content/CVPR2025/papers/Song_RoboSpatial_Teaching_Spatial_Understanding_to_2D_and_3D_Vision-Language_Models_CVPR_2025_paper.pdf) 和 [PAC Bench](https://pacbench.github.io/) 说明空间关系、物理属性及执行约束已有相关评测。

**候选贡献而非结论：** 研究证据时效、未知空间与局部交互几何之间的关系，并评估它们对跨类别行动判断和观察成本的影响。下一步需要逐篇检查最相近方法的表示、对照、假设与可复现性，才能判断是否足够新颖。
