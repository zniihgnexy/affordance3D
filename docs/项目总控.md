## 一、项目的核心目标

研究如何从**视频**中构建并利用对**三维环境的记忆**，让系统能够理解环境中的物体、空间关系、可行交互和环境随时间的变化，并为未来与机器人系统融合提供有用的信息。

项目与视觉—语言—行动模型（VLA）和机器人相关，但当前研究工作**不必须实现真实机器人的底层控制**。研究成果可以停留在 VLA 相关仿真、面向机器人的环境记忆系统，或其他能够充分回答研究问题的阶段。最终范围需要根据研究问题、数据、平台和实验条件确定。

这一方向与博士研究项目中“使用视频构建三维环境记忆系统”的重点保持一致。视频、三维环境记忆和机器人相关的行动理解是当前主线。

## 二、为什么要研究这个问题

自然场景中，执行一个动作需要的不只是识别物体的语义类别。系统还需要理解场景的空间结构、物体之间的关系、哪些位置可支持某种交互，以及动作发生后环境如何改变。

例如，一个物体能否被放置，可能与支撑面的几何形状、空间和物体自身属性有关。桌面、椅面和厨房台面可能共享某些与“支撑物体”有关的条件。如果系统只记住特定物体类别与动作的关联，面对没有见过的类别或环境时可能难以迁移。

这里提出的是**待验证的研究动机**：将与任务有关的几何、空间或功能信息表示出来，可能有助于跨场景、跨物体类别的泛化。不能仅凭几何就假定动作一定可行；根据任务，材质、摩擦、质量、稳定性、动力学、语义和机器人自身能力等因素也可能重要。

## 三、当前初始设想

### 1. 视频输入与三维环境记忆

系统以视频为主要输入，探索如何构建可供后续查询、推理或行动使用的三维环境记忆。潜在记忆内容包括场景几何、物体及其空间关系、交互机会、时间变化和观察的不确定性；具体应该保存哪些内容、采用什么形式，尚未确定。

需要进一步区分：系统保存的是静态场景地图、随时间更新的动态场景记忆、过去交互的经验记忆，还是它们的组合。如何从视频得到可靠的三维信息，也取决于相机、数据类型、遮挡和重建能力。

### 2. 研究 perception 与 reasoning 的解耦

初始想法是在三维环境中探索将**感知**与**推理**解耦，减少系统对特定语义类别标签的依赖，并更关注可跨类别迁移的空间、几何或功能关系。

例如，让系统关注“该区域是否具有支撑物体的条件”，而不是仅依赖“这是一张桌子”来判断。这里的“解耦”目前是研究方向，并不预先规定必须使用完全独立的模块，也不排除语义信息的合理作用。要解耦哪些信息、采用何种表示、如何训练和评估，都需要进一步明确。

### 3. 参考 AROS 的几何方法

[AROS](literature/aros-guide.md) 使用人和环境之间的几何接近关系与空间余量来描述交互，是理解和构建几何 affordance 流程的参考。可以研究其中的表示方式能否融入项目的记忆、推理或评估流程。

AROS 主要研究给定人体姿态在环境中的静态交互位置；其方法不能直接证明任意机器人放置动作可行。这里把它作为**可能借鉴的研究思路**，而非已经选定的最终方案或已经实现的系统组件。

### 4. VLA 与机器人融合

VLA 是未来连接环境理解与机器人行为的一个候选方向。项目可以研究如何让 VLA 使用三维记忆、如何用 VLA 检验记忆的价值，或先在仿真中评估；也可以优先研究记忆系统本身。

目前尚不确定 VLA 模型和记忆系统的具体关系，例如：记忆是否作为 VLA 的输入、外部查询模块、训练监督、预测状态，还是独立系统。VLA 不是已经确定的唯一实现路径，也不要求从头训练大型模型或完成真实机器人控制。

## 四、项目当前的工作假设

以下是对已有想法的整理，均需通过文献、数据和实验验证：

- 从视频建立的持久三维环境记忆，可能帮助系统利用当前视野之外或此前观察过的信息。
- 对几何和功能关系的适当表示，可能帮助模型将某些交互知识迁移到新的物体类别和场景。
- 显式的几何 affordance 信息可能与视频、语言和学习得到的语义信息互补。
- 在相同任务和条件下，将使用记忆的系统与不使用记忆的基线比较，可能帮助判断记忆是否真正有用。

这些假设不等同于研究结论，也不要求所有内容必须由同一个模型完成。

### 已确定的硬件与实验条件

- **远程训练：** 可以使用学校的 GPU 计算资源，但只能通过 SSH 连接。训练工作可以部署在该远程环境中，因此候选方法应考虑无图形界面的安装、训练和运行方式。
- **仿真、测试与可视化：** 可以使用一台配备 NVIDIA 5060 的设备进行仿真；实际测试或可视化可以安排在有图形界面的服务器上。具体平台能否在该设备和服务器环境中运行，仍需逐项验证。
- **跨环境协作：** 可以考虑在学校远程 GPU 上训练，再将模型、必要的数据和配置转移到有图形界面的环境进行测试或可视化。具体迁移方式、依赖、存储及访问权限尚待确认。

以上是项目负责人提供的固定资源条件，不代表已经选定仿真平台或验证过任何模型的运行能力。学校 GPU 的型号、显存、数量和可用时长，以及 5060 设备的具体配置仍待确认。

## 五、尚未确定的问题

以下问题针对项目的整体范围；第七节的 Algorithm Track v1 对首版实验提出了工作假设，但不预先限定项目的最终范围。

1. **研究对象和任务：** 面向桌面操作、室内移动操作、人与环境交互，还是其他任务？“放置”是否只是说明性例子，还是首个实验任务？
2. **视频与环境：** 单目还是多视角？预录视频还是连续输入？静态场景还是含有人、物体运动的动态场景？
3. **记忆的定义：** 系统需要记住什么、多长时间、如何更新、如何处理遮挡、错误与环境变化？
4. **记忆的使用者：** 人类查询、推理模型、VLA、规划器或仿真机器人如何访问记忆？
5. **感知与推理的边界：** 哪些表示更适合保留几何信息、哪些需要语义信息、它们如何交互？
6. **AROS 的适用性：** 是直接使用其几何描述方法，借鉴其接近关系和空余空间的思想，还是只作为比较对象？
7. **Benchmark 的含义和范围：** 是构建新的数据集和评测基准、使用现有 benchmark，还是在已有仿真平台上设计一组实验？当前没有定论。
8. **VLA 与记忆的关系：** 是将记忆接入已有 VLA，独立评测记忆，还是比较不同系统架构？
9. **可用资源：** 在上述已确定的远程 GPU 和仿真设备条件下，具体数据、传感器、仿真平台、GPU 详细配置及是否能接触真实机器人硬件尚待确认。
10. **成功标准：** 除任务成功率外，是否需要评估三维重建、记忆准确性、空间推理、时间一致性、跨场景泛化及计算开销？

## 六、初步研究路径（可调整）

1. **明确问题与数据条件：** 梳理视频、三维记忆、具身空间推理与 affordance 相关文献，盘点可用的数据和平台。
2. **建立可操作的任务定义：** 选一个足够具体的场景与问题，明确输入、记忆内容、输出和评测方式；优先考虑现有数据集或平台是否适用。
3. **建立基线：** 根据条件选择无长期记忆、有场景记忆、或不同表示方式的合理基线，确保比较能回答研究问题。
4. **探索候选方法：** 研究几何 affordance、语义关系、时序信息与环境记忆如何结合；必要时借鉴 AROS 的思想。
5. **评估与调整：** 检查记忆质量、场景变化、未见物体和环境泛化，并按研究范围选择是否接入 VLA 或仿真机器人。

这些步骤是可修改的研究安排，不是要求按固定顺序完成的承诺，也不替代后续实验设计。

## 七、Algorithm Track v1：面向交互的三维几何记忆

**状态：研究设计初版 / 待项目负责人审阅、修改和实验验证**  
**记录日期：2026-10-28**

第一阶段先将三维记忆系统作为独立的算法研究对象：从连续视频构建、更新和查询环境中与交互有关的局部几何关系。机器人控制、VLA 接入和语言输出可以在后续研究，不是本阶段的前提。

### 研究目标与核心设想

- **局部几何是交互的基本单元。** 研究物体—物体和物体—环境的局部关系，以及这些关系如何随时间和环境变化；不将某种局部几何固定映射到某个物体类别或动作标签。
- **首版输入条件：** 仿真中的连续 RGB-D 视频、相机内参和已知相机位姿。该条件是实验起点，不代表项目最终限定于 RGB-D 或仿真。
- **记忆内容：** 探索将已观察的空间几何、动态对象、局部几何关系，以及观察时间、可见性与来源证据组合起来。系统需要区分当前有证据的状态、历史记录以及未知或冲突状态。
- **关系表示：** 借鉴 AROS 和 Interaction Tensor 关于交互双方几何接近与空余空间的思想，探索可查询的局部几何关系 atom 或其他表示。首版的离散关系记录是候选设计，是否改为连续几何场仍待讨论。该方法是受 AROS 启发的研究方案，并非 AROS 本身已经具备的动态记忆能力。
- **更新与查询：** 在观察到场景变化时更新相关对象、局部关系及证据；遮挡或没有观察到变化时，不把未知区域当作空闲，也不将旧关系直接当作当前事实。查询结果应能回溯到相应的观察和时间。
- **后续扩展：** 在记忆算法得到验证后，研究如何将局部几何与交互结果、动作意图和可学习的理解表征结合；该表征未来可以连接连续动作策略或 VLA，也可以探索可解释的可视化或文本接口。

### 边界与评测

当前的几何关系不等同于已验证的真实接触、物理 affordance 或机器人动作可行性；摩擦、质量、固定方式、动力学以及执行者能力等也可能影响交互。动态对象识别和跨帧关联是待解决问题；若使用仿真实例或位姿真值，须明确标记为额外信息或理想上界，并与仅使用观察输入的结果分开。

首版拟通过多视角几何与关系准确性、遮挡下的历史和当前状态查询、物体移动后的更新与残影、以及记忆和查询成本进行独立评估；与当前帧、普通融合和动态对象记忆等基线在相同观察条件下比较。关系 atom、时间及证据管理的实际增益和研究创新性均需文献与实验验证。
