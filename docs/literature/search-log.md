# Scope and search log

**Review type:** exploratory scoping review, not a systematic review. **Date:** 28 October 2026.

**Question:** How did AROS develop from geometric affordance and human–scene interaction research, and what ideas or limitations matter when adapting it to a related robotics task?

**Inclusion:** AROS itself; papers it identifies as foundational or compares with; selected related primary research on action maps, geometric representations, and simulated affordances. English-language sources were prioritized. There is no fixed publication-year cutoff. We excluded general robotics papers without a clear connection to this question. This is a curated starting set, not a complete screened corpus.
