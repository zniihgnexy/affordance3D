# 研究文档

本目录汇集视频驱动的三维环境记忆、交互理解与机器人方向的研究资料。以下三个文件是长期维护的固定入口：研究进展发生变化时更新对应入口，并链接详细记录；历史版本保留用于追溯。

1. [Pipeline 与实验路线](pipeline.md)
2. [Literature：文献与研究脉络](literature.md)
3. [数据与仿真平台](data-and-simulation.md)

项目方向和边界以[项目总控](项目总控.md)为依据。总控中的维护规则要求项目负责人明确批准后才能修改；候选设计或新发现不会自动改变项目范围。

`research/` 和 `literature/` 保存详细研究文档，`research/figures/` 保存文档配图，`outputs/` 保存数据、仿真调研表格及其图像。文件内容及日期代表记录时的状态，模型、论文和平台信息需要在使用前重新核验。
