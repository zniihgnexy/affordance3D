**整体流程参见 [Pipeline v3：任务驱动的 Affordance 交互检索](research/任务驱动Affordance检索_Pipeline_v3.md)，当前实施结合上方11月5日补充设计。** 项目负责人于 2026-11-03 确认的流程为：视频 → 感知 → 可检索交互记忆 → 结合当前环境与任务目标的 search → 核心视频片段、关键帧和 affordance maps / tokens → VLA → 目标机器人动作。

v3 曾将以局部几何、交互过程与状态变化为依据的示范检索作为算法核心，探索跨视角、跨机械臂与工具以及人类操作视频。结合11月5日补充，当前原型首先研究环境记忆及其 affordance 特征层，检索是读取方式之一；机器人与 VLA 是后续候选应用。目标机器人动作仍需适配；检索用于 VLA 训练还是执行时条件尚未确定。完整 v3 文档保存两张用户草图、接口、候选贡献及待验证问题。

本版是经确认的研究方向，尚未实现或验证；具体结构和训练方案仍可调整。2026-11-02 的 proposal 与综述作为背景参考。

### 首轮预期目标

| 阶段 | 拟验证的问题 | 预期检查与边界 |
| --- | --- | --- |
| E0：数据和空间对齐 | 同一功能部位在多视角 RGB-D 与相机位姿下能否正确投影和对应？ | 从 SceneFun3D 小子集开始；标注或完整扫描仅作单列 oracle 诊断与评估。对齐通过只说明数据链路可用。 |
| E1：历史记忆读取 | 当前视野之外、此前已经观察的功能区域能否从记忆中找回，并显示来源证据？ | 比较当前帧和普通视觉历史，按时间前缀建记忆；区分已见、当前不可见和从未观察。 |
| E2：Affordance 特征层 | 在相同历史与可比预算下，功能监督特征是否优于普通历史和参数匹配视觉分支？ | 比较 C0–C3，主要测功能区域 mIoU 和证据帧 Recall@3；测试标签不进入记忆。额外监督需单独报告。 |
| E3：环境与状态变化 | 观察到遮挡、占用或状态变化后，记忆能否保留或更新证据？ | 作为后续受控实验；几何兼容性与真实交互成功分开评价。 |

上述均为实验计划，不是已取得的结果；场景数量、门槛和训练预算是待验证建议。具体设置、继续条件及资源限制以[快速验证计划](research/环境记忆Affordance层_快速验证实验计划_Mac_Isambard_2026-11-05.md)为准。
